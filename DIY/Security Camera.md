# 屋檐墙角 360° 摄像头安装 —— 完整方案总结

> 目标:在外墙角的屋檐下安装一个 360° 摄像头(Eufy Floodlight Cam E340),同时覆盖 driveway 和 front yard。
> 难点:外角一侧屋檐底是斜的,且**没有任何现成平整表面可直接壁挂**,因此必须用木板+托架**创造一个水平安装平面**——这是整个方案的出发点。
>
> ⚠️ **摄像头实况(重要)**:E340 不是小摄像头,而是 **1.3–2.3kg、约 320(高)×185(宽)×216(深)mm 的大块头**,且是 **pan/tilt 会转动**的机型、**240V 硬接线**。重量和高重心显著影响固定方案(见下)。

---

## 一、最终实施方案(三角托架 + 打砖)

**核心结构:**
摄像头 → 固定在一块 primed pine 木板上 → 木板搁在两个三角托架上、用短螺丝固定 → 托架用不锈钢膨胀栓打进**砖块本体**承重。

**为什么这是最优方案:**
- 承重完全交给砖墙,**绕开了"从屋顶腔找承重结构(bearer)"的整个难题**。
- 三角托架的斜撑把向下的力转成对墙的压力,抗弯能力远强于普通 L 角码。
- 木板是"躺"在托架上(简支/托盘受力),不是"探出去吊空"(悬臂受力),所以**不会从中间下垂或断裂**。

**⚠️ 因 E340 重量大(1.3–2.3kg)、重心高(机身 320mm 高)、会 pan/tilt 转动,方案升级:**
- 托架选**重型带斜撑(heavy duty stayed)**款,标称承重明确,别用薄的装饰托架。
- 膨胀栓**每个托架打满 3 颗**(不是 2 颗),两个托架都用。
- 摄像头用**原厂底座 + 全部螺丝孔**贴实固定,压低高重心的撬动影响。
- 板与托架臂之间**每处打 2–3 颗螺丝**,消除转动余地。
- **加一个小 L 角码**把板内侧上缘额外锁向砖墙——不承重,专门**防止整块板绕托架前后翻转/晃动**(高重心机型的真正风险是被撬松,不是被压断)。
- 金属螺纹连接处(膨胀栓螺母、金属底座螺栓)可点**蓝色 Loctite 242/243**(可拆卸)防振动松脱;**木螺丝和膨胀塞上不涂**(螺纹胶对木头/膨胀塞无效)。**切勿用红色 Loctite**(永久,将来拆不下来换 SD 卡)。

**木板规格:**
- 长(沿墙方向)约 700–800mm,宽/进深(往外伸)约 190mm,厚 18mm。
- 普通长方形,四个直角,jigsaw 锯一刀即可。**不做楔形斜角块**(jigsaw 切复合斜角切不准)。
- 摄像头装在板的外缘一角,镜头**刚好探过墙角线 5–10cm**,保证两侧视野不被自家墙体遮挡;固定点集中在靠墙半边。

**安装要点:**
1. 木板与斜檐之间形成的三角空腔**开口朝下**,靠重力自然排水,风阻可忽略。
2. 空腔顶缝**做薄封挡雨即可,不要灌满密封**——困住的水比流动的水更毁木头。
3. 空腔开口用**不锈钢/铝网**封住,防鸟筑巢、防黄蜂。
4. 所有穿透檐底/墙体的孔用**中性硅胶**封边,防 gutter 渗水顺孔而下。
5. 走线:摄像头出线后就近钻孔进屋顶腔,或沿墙走白色 PVC 线槽;入孔做 **drip loop**(线先向下弯 U 再进孔)。

**关于倾斜排水(可选,非必需):**
- 位置在屋檐深阴影,几乎不淋雨,可不刻意做坡度。
- 若要做,让**外缘略低 2–3°**(即靠墙内侧垫高 6–8mm 垫片),水就往外排。
- 注意:是垫**内侧**抬高内侧,不是垫外侧。

**关于感应灯(现场已有一盏 240V 双头感应灯):**
- **大概率不用拆**。灯在靠里位置,摄像头在外角,空间上可绕开。
- 🔴 真正要处理的是**灯的电缆走向**——打膨胀栓进砖墙前,必须确认钻孔不碰墙内电缆。
- 夜间过曝风险:感应灯触发时强光直射鱼眼镜头会导致画面瞬间过曝。
  对策:让灯处于摄像头**侧后方**而非正前方;摄像头尽量装得比灯**高**、镜头略朝下。
  测试:晚上让灯亮一次,手机举到摄像头预定位置录一段,看会不会白屏。

## 二、动手前必做的三个确认(比买东西更重要)

1. 🔴 **查感应灯电缆走向** —— 上屋顶腔看,或从下面探查,确认钻孔位置安全。
2. **硬纸板实地比划** —— 剪出板的尺寸举到目标位置,确认不撞灯、镜头视野不被灯遮挡、晚上测过曝。
3. **确认打砖那面墙可靠** —— 挑砖实、无电缆、朝向合适的那一面墙打(只需一面,不要两面都打)。

## 四、被否决的方案及原因(避免走回头路)

| 被否决方案 | 否决原因 |
|-----------|---------|
| **楔形斜角块填平斜檐** | jigsaw 切复合斜角切不准,会留缝进水进虫。改用平板悬挑/托架托举。 |
| **纯悬挑(往外挑,只靠檐底螺丝吊装)** | 需精确找 bearer、算悬臂力矩、防劈裂,且是悬臂受力长期可能下垂。三角托架方案完胜。 |
| **普通 L 角码** | 承重全靠直角焊缝,重了会掰弯。三角托架有斜撑,抗弯强得多。 |
| **膨胀螺丝直接打砖(最初方案)** | 最初往外挑时,板背后是悬空屋檐、没有砖,故当时否决。**靠墙方案下背后就是砖,打砖反而变成正解**——此条是"随方案演进而反转"的。 |
| **实木大板 / MDF / 刨花板 / 未处理松木** | 会拱、会烂,户外撑不过两年。用 H3 primed pine 或结构胶合板。 |
| **油性漆做面漆** | 易脆裂、封闭膜困水、白色会黄变。外木用水性丙烯酸(acrylic)。 |
| **British Paints Clean & Protect** | 那是**室内**漆。要用 4 Seasons **外墙**线。 |
| **喷罐漆** | 无法调色匹配、膜太薄、不留补漆余量。用罐装刷涂。 |
| **Merbau/铁木做面板** | 对遮蔽位置是杀鸡用牛刀:贵、重、单宁渗色会把白漆染黄、难钻难拧、表面含油排斥水性漆。primed pine 更合适。 |
| **横向角铁"垫在板下防断/防下折"** | 板托在托架上不会断/下折,这个目的的角铁没必要。**但因 E340 重且重心高,改为加"防翻转"角码**(锁板内侧上缘向墙),目的是防整块板被撬晃,不是防断——见方案升级项。 |
| **从第二面墙再加垂直托举** | 过度约束(over-constraint),两方向固定点会互相较劲。应挑一面更好打的墙,不要两面都上。 |
| **拆感应灯** | 空间可绕开,不必拆。拆 240V 硬接线灯要动电、要持牌电工、留洞要补,是最麻烦的选项。真正要处理的是灯的电缆走向。 |
| **给不锈钢/镀锌托架直接刷漆** | 光滑活性表面附着差,需蚀刻底漆,麻烦。若要白色,从白色喷漆碳钢款起步最省事。 |

## 五、受力分析 —— 系统学习计划

**你需要的学科(由近到远):**

1. **静力学 (Statics)** ← 核心。力怎么平衡、怎么传递。教你画**受力图 (free body diagram)**,这是一切分析的起点。
2. **材料力学 (Strength of Materials / Mechanics of Materials)** ← 核心。同样的力,材料/形状会怎样弯或断。核心概念:**应力、弯矩、挠度**。
3. **结构力学 (Structural Mechanics)** ← 天花板,DIY 用不到,不必从这入手。
4. **建筑规范 / span table** ← 把结论查表化,免计算。

> 你的 DIY 甜蜜区 = 静力学 + 材料力学 + span table 速查。数学门槛低,概念都能在家里的架子/屋檐上摸到。

**学习路径(按顺序,别贪多):**

1. **建立直觉(一两个晚上)**:YouTube 看
   - **The Efficient Engineer**(应力/弯矩/挠度动画,零废话)
   - **Practical Engineering**(把力学放进真实工程)
   - 搜:statics free body diagram / bending moment explained / cantilever vs simply supported beam
2. **学画受力图**:Khan Academy 或任意 statics 入门。这是分析任何 DIY 结构的通用工具。
3. **需要数据时查 span table**:澳洲 **AS 1684(Residential Timber-Framed Construction)**,含大量"多大跨度用多粗梁"的表。把"算"变成"查"。
4. **想深入再走**:MIT OpenCourseWare(8.01 力学 → 1.050 Statics);教材 Hibbeler《Engineering Mechanics: Statics》+《Mechanics of Materials》当概念字典翻。

**学科层级一句话记忆:**
物理(力是什么)→ 静力学(力怎么平衡/传递)→ 材料力学(材料受力会怎样弯/断)→ 结构力学(设计整个结构体系)→ 规范/span table(结论查表化)

> 你这几天从"悬臂会不会断"到"托架改变受力模型"到"过度约束反而不好"的推理,已经是在做静力学的定性分析了。你不是从零开始,只是缺一套术语框架把直觉系统化。

## 六、施工顺序速查

1. 三个确认(电缆走向 / 纸板比划 / 选定打砖墙面)
2. jigsaw 锯木板成长方形 → 钻 5mm clearance 孔 → 切口补底漆 → 六面(或已底漆则面漆)刷 British Paints 两遍 → 彻底干透
3. rotary hammer(SDS 8mm,开 hammer 档)打砖块本体 → 装 DynaBolt → 固定托架(白色喷漆款补好破口)
4. 木板搁上托架 → 短螺丝从下往上固定到托架
5. 装摄像头(镜头探过墙角线)→ 走线(drip loop + 中性硅胶封孔)
6. 封三角空腔开口(网)+ 封现场那条缝
7. 补螺帽孔、补漆收尾

> 核心口诀:**打砖用冲击档、钻木板别用冲击;打砖块本体不打砖缝;所有穿透孔封边;顶缝别封死。**
